#👟 ShoeEnchant

ShoeEnchant is a responsive shoe e-commerce website built with React.js and Redux. I created this project to gain practical experience with Redux and global state management, particularly to understand how it can help avoid prop drilling.

#🔗 Links
● Live Demo: https://shoeenchant.netlify.app/
● GitHub: https://github.com/AryaShewde/Shoes-shop-web

#✨ Features
● 👟 Browse shoes
● 🔍 Search and filter products
● 🛒 Add products to cart
● ➕ Increase/decrease product quantity
● 🗑️ Remove products from cart
● 📱 Responsive design
● 🔄 Redux for global state management

#🛠️ Tech Stack
● React.js
● JavaScript
● Redux
● Bootstrap
● HTML5
● CSS3

#🧠 What I Learned

This project helped me understand:

● Redux store, actions, and reducers
● Global state management
● Data flow between React components
● How Redux can help reduce prop drilling
● Managing cart state in a real-world use case

#🚀 Getting Started
git clone https://github.com/AryaShewde/Shoes-shop-web.git
cd Shoes-shop-web
npm install
npm start
